# earthmc-dynmap+
A web extension for all browsers. Designed specifically for EarthMC's dynamic map, coming with a great multitude of useful and cosmetic features.

## Features
When I created the extension, the main idea was to group countries together into their respective organizations and "meganations". Later on, in the natural course of things, the number of new features began to grow with new releases.
### Most notable features
* Three map modes: default, alliances, and meganations
* Archive mode to view old, saved claims and statistics (archived by the Wayback Machine website)
* Locate towns, players, and nations
* Total revamp of the aesthetics
* Look up a player by clicking their name
* Dark mode
* View real country and provincial borders
* Extensive configuration
* Automatic updates

## 2 ways to install the extension
> [!TIP]
> This works for desktop and mobile (if your mobile browser supports extensions)! For the best experience, it is also recommended to use ad-blockers.

### 1. Extension (recommended)
> [!IMPORTANT]
> Only for Chrome-derived browsers (such as Google Chrome, Microsoft Edge, Opera, and Brave). For other browsers, please install the userscript.

Install the extension from the Chrome Web Store by [clicking here](https://chromewebstore.google.com/detail/earthmc-dynmap+/hgfdjfdkneceljokdelhiikgnndpmcgh).

### 2. Userscript
1. Install the Tampermonkey extension for your browser.
    - [For Chrome-derived browsers](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
    - [For Firefox](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/)
    - [For Safari](https://apps.apple.com/us/app/tampermonkey/id1482490089)
2. Install EarthMC Dynmap+ by [clicking here](https://github.com/3meraldK/earthmc-dynmap/releases/latest/download/userscript.user.js). It may be trickier to get it working on mobile.

## Maintainability
Unexpected updates to EarthMC may cause this extension to temporarily stop working. We are neither affiliated with EarthMC nor responsible for archiving map snapshots. Check for announcements or report bugs [here](https://discord.gg/AVtgkcRgFs).
